# Hydrofit.do Web

Browser companion for HydroFit.do. It covers the hydration functions from the Android app:

- Onboarding (gender, weight, wake, bedtime, and the plan walkthrough)
- Today: progress ring, container logging, custom amount and time
- Plan and exportable schedule
- Stats for day, week, month, and year
- Tips, achievements, profile photo, and notification inbox
- Reminders while the tab is open
- Settings for theme, units, and restore

Data stays in this browser. The site does not sync with the Android app.

```bash
pnpm dev
```

Open http://localhost:3000. The privacy policy is at `/privacy`.
